# Warriors: Fireheart's Quest

A side-scrolling MakeCode Arcade game based on Erin Hunter's *Warriors* books.
You play as **Fireheart** of ThunderClan.

## Play it

**Import from GitHub (easiest):**

1. Go to https://arcade.makecode.com
2. Click **Import**, then **Import URL**.
3. Paste **https://github.com/herossteamcenter/warriors** and click **Import**.

**Or paste the code:**

1. Go to https://arcade.makecode.com and click **New Project**.
2. Switch the editor to **JavaScript** (top middle).
3. Select everything in the editor, delete it, and paste in the whole of `main.ts`.
4. The game starts in the simulator on the left.

Stay in the JavaScript view. The game uses classes and generated art that the Blocks view can't show.

## Controls

| Button | Action |
| --- | --- |
| ← → | run |
| A (or ↑) | jump |
| B | claw attack |

Defeat every rival warrior in a level, then touch the **StarClan star** to move on.
Catch mice (fresh-kill) to get a life back, up to 9 lives.

## Levels

1. **Sunningrocks**: cross the river on the stepping stones and drive out RiverClan and their deputy, Leopardfur.
2. **WindClan Moor**: fast WindClan warriors. Don't fall into the gorge!
3. **The Thunderpath**: a ⚠ sign warns you before a monster (car) roars past. Jump over it or wait on the rocks. Monsters hit ShadowClan cats too.
4. **ShadowClan Camp**: fight your way in and defeat **Tigerstar**.

## How it's built

- **One art style:** every cat uses the same 24×16 template with a 1px black outline and the same poses. Each Clan cat is a recoloured version of that template (see `makeSkin` in `main.ts`): Fireheart is a flame-coloured tabby, RiverClan cats are blue-grey, Leopardfur is golden with spots, WindClan cats are pale, ShadowClan cats are dark, and Tigerstar is a big dark-brown tabby.
- **Animations:** every cat has idle (tail swish and blink), walk (4 frames), jump, claw attack (crouch, swipe, strike) and hurt. They're mirrored for facing left. The mouse, the monsters and the warning sign are animated too, and so are the river and star tiles.
- **Tilemaps with custom tiles:** 18 hand-generated 16×16 tiles (grass, dirt, heather, rock, river, Thunderpath road, marsh, bramble, tree trunk, leaves, fern, star…). Each level is drawn as ASCII art in `LEVELS` and turned into a real MakeCode tilemap with walls. Edit the letters to redesign a level. The legend is in the comment above `LEVELS`.
- **Parallax backgrounds:** each level has a background that scrolls behind the tiles: forest day, moor, Thunderpath at dusk, and ShadowClan at night.

## Changing the art

The pixel art is generated by `tools/make_art.py`. Edit it and run:

```
python3 tools/make_art.py
```

This rewrites the `GENERATED ART` block inside `main.ts` and makes `art_preview.png`, a sheet showing every cat, animation frame and tile.
